# Order Tracking Screen

Responsive React/Vite implementation of the e-commerce order tracking task. Includes normal tracking plus all required edge states: delayed order, delivered-but-not-received, and tracking-not-available-yet. Support, issue reporting, order details, refresh, loading state and responsive 360–430px mobile layouts are implemented with mock/static data.

## Local setup

```bash
npm install
npm run dev
```

Production validation:

```bash
npm run lint
npm run build
npm run preview
```

## Vercel

Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`. Install command: `npm install`. No environment variables are required.
